# Employee Analytics SQL Project

A SQL-based employee analytics and management system designed for handling employee records, generating reports, performing data cleaning, and analyzing workforce data using SQL queries.

## Features

- Employee database management
- SQL queries for employee reporting
- Data cleaning operations
- Joins and subqueries
- Common Table Expressions (CTEs)
- Stored procedures
- Triggers
- Data analysis queries

## Technologies Used

- SQL
- MySQL
- VS Code

## Project Structure

```text
EmployeeManagement/
Employee Report/
EmployeeReport_DataCleaning/
EmployeeReport_DataVisualization/
Stored Procedures/
Triggers/
```

## Purpose of the Project

This project was developed to practice and implement SQL concepts used in database management and business analytics systems.
